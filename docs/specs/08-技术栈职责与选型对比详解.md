# 一期技术栈职责与精简取舍

2026-11-10。用户要求一期核心尽量精简；选择依据是现有代码、真实业务需求和切换成本，不是技术数量或市场排名。版本只查锁文件，状态只查handoff，不在多份文档维护测试总数。

|---|---|---|
|FastAPI/Pydantic|HTTP、授权依赖、DTO/OpenAPI、严格模型结构|已实现并有回归，Python便于复用提取/规则；无必要再引入第二后台框架|

## 已完成但改为可选的能力

T20语义索引后端保留，Milvus/etcd置semantic profile，Embedding由管理员明确开启。它帮助自然语言找人，不是岗位匹配分数或人才事实库。T21直接读冻结履历与岗位，基本人才库用SQL查询，因此一期主线不需默认启动向量服务。高级界面、rerank、知识索引与调优二期再做；不删除旧索引数据。

## 已完成代码中的精简

FixedGraphRunner保留历史接口，但一期只转交受控网关，不再每次compile一个单节点LangGraph。权限、schema、引用和模型状态检查仍在；跨任务恢复仍属于MySQL任务，不增加图checkpointer。旧锁中包暂时保留，避免本轮无关依赖重解析；真实出现多节点/分支再评估图编排。

公开少量跨领域方法使事务/授权边界可见，不创建通用Repository或所有领域共享的大Service。查询归领域；状态规则与I/O分离仅在确有内容时拆文件，不为每个类新增一层目录。

## 明确二期或未采用

知识问答、AI出题、看板/ECharts、培训框架、部门负责人协作、复杂OCR/旧DOC、高级语义/rerank移二期。Dify、通用拖拽Agent、MCP业务运行、Neo4j、Kafka、多租户和微服务不属于一期；开发工具插件不等于产品运行依赖。保留替换点，不提前实现所有候选方案。

评价替代栈必须在同一输入/指标下测质量、资源和运维收益。本文不声称某数据库/模型在所有规模更优，也不以安装成功或依赖数量衡量架构质量。
