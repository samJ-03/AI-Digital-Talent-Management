## 1. 结论与证据口径

当前主栈是：Next.js/React/TypeScript + Ant Design/TanStack Query；Python/FastAPI/Pydantic + SQLAlchemy/PyMySQL/Alembic；MySQL + Redis/Celery + 应用自建调度器 + MinIO + Milvus；HTTPX模型网关 + LangGraph固定图；DeepSeek官方deepseek-flash及百炼text-embedding-v3；Docker Linux容器/Compose + Nginx + 本地Mailpit。

这不是“所有功能都已完成”的清单。当前T01～T11完成，下一步T12，完整招聘流程、完整业务界面和生产部署尚未完成。最近一次完整本地测试记录为190通过，前端lint/typecheck/build通过；这是既有记录，本次文档核对没有重新跑业务回归。

| 状态 | 本文含义 | 不能推导出的结论 |
|---|---|---|
| 已接入并验证 | 当前代码已调用，存在对应测试或真实合成探测证据 | 不代表所有未来业务功能、并发或生产指标达标 |
| 已安装/声明依赖，功能待实现 | 已进入锁文件或配置，但目标业务还没接上 | 不能写成该功能已上线 |

模型名称不是可下载权重摘要。云端model_digest允许NULL，配置修订ID、模型名和实际维度组成可追踪身份；不能用模型名字或自造hash冒充权重digest。本地模型才核验实际权重digest。

主网关使用HTTPX直接访问白名单官方地址，校验返回JSON、发布schema、业务类型和来源引文。JSON格式正确不代表内容真实，引用校验也不等于所有自然语言结论都已证实。DeepSeek支持JSON输出的协议依据见[官方文档](https://api-docs.deepseek.com/guides/json_mode/)。七个固定流程初始关闭，模型配置通过测试不等于自动开启招聘任务。

第三方代理、本机偶然发现的bge-m3/gemma/qwen缓存不属于当前已采用主模型。模型Key、主密钥或来源.env内容不写入本文。
