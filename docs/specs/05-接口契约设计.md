# 接口契约设计

2026-11-10一期范围修订。保留104条历史API ID映射，不要求一期凑足数量。当前implemented/phase1待做/phase2延期/optional以docs/api-manifest.json标识；实际结构由OpenAPI导出，业务语义仍由本稿/PRD明确。二期API052、079～086、095不阻塞一期；032/036已有语义后端保留可选。

## 1. 全局约定

业务前缀统一/api/v1，以下路径均省略此前缀；候选人接口独立/candidate分组，前端入口/exam。GET不产生业务写副作用（GET读到超时可以显示effective_state，真正提交由scheduler或POST处理，不在GET偷偷发邮件）。

认证：后台session与考试session分别使用不同Cookie名与Redis命名空间。HttpOnly/Secure/SameSite；写请求CSRF token。候选人只有本考次权限，无后台role。公开核验接口同样限频。管理员无默认HR业务读取权；HR每条资源必须验证job/department或共享人才权限。

成功封套：{code:"OK",message:"成功",data:...,request_id:"uuid"}。201创建，202任务受理，200查询/完成；错误HTTP状态与业务码一致，不统一返回200。失败封套：{code:"ERROR_CODE",message:"可读提示",data:{field_errors?,conflicts?},request_id}，不得返回raw_error、堆栈、模型密钥或秘密答案。分页{items,total,page,page_size}，page≥1，默认20，上限100，稳定created_at/id排序。

ID全是字符串；时间ISO8601 UTC如2026-11-04T02:00:00Z；分数保留2位小数，范围由题目满分或100决定；金额无关。可变资源响应含version并返回ETag，修改携If-Match，版本不符409 VERSION_CONFLICT。无权限对象可统一404避免枚举；已知可见对象操作不足403。

创建任务、发布、邀考、提交、finalize、阶段流转等关键POST要求Idempotency-Key。idempotency_records按actor+operation+key唯一并校验请求hash；同key同内容返回同资源引用，同key异内容409。客户端重试使用原key。领域唯一约束仍独立生效；不得靠短时Redis锁替代考次唯一约束。

## 2. 核心请求/响应DTO

### 2.1 岗位与筛选

JobVersionDraft：{description,conditions:[{key,field,operator,expected,required}],match_weights:{skills:50,experience:35,responsibilities:15},invite_threshold:75,paper_version_id?,invite_valid_hours:72,mail_template:{subject,body}}。示例值仅说明结构，不是写死业务默认。field白名单education/major/relevant_years/skill/certificate等；operator与值类型必须匹配；unknown不是不符。age如启用仅人工复核，不参与自动匹配评分。

JobView：{id,title,department_id,headcount,status,current_version_id,auto_invite_enabled,version}。readiness：{ready,blocking_reasons:[code]}，例如PAPER_NOT_PUBLISHED、MODEL_UNAVAILABLE、MAIL_NOT_VERIFIED。

EvaluationDetail：{id,application_id,resume_version_id,profile_id,job_version_id,state,screening_result,invitation_mode,is_current,error_code,screening_context,conditions:[{key,required,expected,actual,result,evidence,reason_code}],match:{state,total_score:string|null,dimensions[],strengths[],gaps[],evidence[]}|null,override_events[]}。match对外统一dimensions，不暴露列名dimension_scores。current在受理新run时切换；旧结果只保留历史，pending新run不得借旧高分邀请。人工继续保留原筛选结果。

### 2.2 导入、人才与画像

ImportBatch：{id,job_id?,status,file_count,items:[{id,file_id,state,error_code?,candidate_id?,resume_version_id?}],created_at}。请求受理不等于全部解析成功，轮询详情直到各item终态。

TalentView：{id,canonical_candidate_id,name,email_masked,education,major,skills,status,current_profile_id,version}；HR详情在授权后可见联系信息，列表默认遮罩。TalentDetail含共享简历画像及有权限的application摘要，其他部门仅“有历史记录”标识。

ProfileView：{id,candidate_id,resume_version_id,version_no,summary,skills,experiences,evidence,authorized_application_views:[]}；前几项只基于共享事实，后者按岗位权限动态附加考试/评价，不进入共享向量。source须含source_type/source_id/locator，HR修正记录reason。

SemanticSearchResult（可选已实现后端）：{items:[{candidate_id,profile_id,semantic_relevance,matched_evidence}],degraded:false,query}。semantic_relevance不是岗位胜任分；异常503返回SEMANTIC_INDEX_UNAVAILABLE，不能伪造空列表。

### 2.3 试卷、邀请、答卷

QuestionDraft：{bank_id,type,stem,options?,answer_key?,rubric,reference_sources[]}。类型single_choice/multiple_choice/short_answer。PaperVersionDraft：{duration_minutes,reference_pass_score?,items:[{source_question_id,max_score,position_no}]}；后端复制题目修订及答案/量表入paper_items。总分由后端求和，题目未approved不能发布。

AttemptView（仅HR）：{id,application_id,round_no,evaluation_run_id,paper_version_id,email_snapshot,invite_status,state,valid_until,started_at?,deadline_at?,objective_score?,current_score_report?,version}。无原始token。Invitation创建同时返回notification_id与处理状态，不承诺邮件实际到达。

VerificationContext：{masked_email,expires_at}，上下文用短期安全Cookie保存，send-code不能接受收件邮箱覆盖。邮箱验证码通过后建立ExamSession，仅允许一个考次。请求body中的invitation_token不记录日志。fragment入口token不得写查询串或Referer。

CandidateExamView（开考前）：{job_title,paper_name,duration_minutes,valid_until,state,server_time,instructions}。CandidatePaperView（开考后）：{attempt_id,state,server_time,deadline_at,items:[{id,type,stem,options?,max_score}],saved_answers:[{paper_item_id,answer,revision}]}。禁止混用内部PaperVersionView，不含answer_key/rubric/参考答案/AI评分。start一次性预建全部题目空答案，重复start不重置计时。

AnswerSave：{answer:{selected_keys:[]}|{text:"..."},expected_revision}。AnswerReceipt：{paper_item_id,revision,saved_at,server_time}。409返回当前revision与当前已保存答案（仅本人），由前端提示冲突，不静默覆盖。首次空行revision=0，首次保存expected_revision=0。

SubmissionReceipt：{state:"submitted"|"processing"|"completed",submitted_at,submission_reason}，只展示提交状态，不展示得分；AI已评分不等于对外开放成绩。deadline后保存返回409 EXAM_DEADLINE_REACHED，调度执行统一提交。

### 2.4 评分、招聘、知识与配置

GradingView（HR）：{attempt_id,state,items:[{answer_id,question,answer,max_score,objective_score?,ai_suggested_score?,ai_reason?,review_state,final_score?,review_revision}],current_score_report?,version}。review与finalize先锁同一attempt；finalized状态直接review返回409，须先reopen-review。全未答卷按所有冻结题目记0，不漏计。FormalScoreView：{report_id,version_no,total_score,objective_score,subjective_score,item_score_snapshot,confirmed_by,confirmed_at}。

阶段变更：{to_stage,reason,expected_version}；reason非空；合法跳转按04定义。AI任务不能调用此HR动作。InterviewNote保存岗位评价，不向共享画像摘要自动扩散。

AnswerWithSources：{answer,sources:[{document_id,chunk_id,title,locator,quote}],insufficient_evidence,model_revision}；引用须存在、属于权限内文档。模型超时504/依赖不可用503，无资料时200且insufficient_evidence=true并明确无据。

MaskedModelConfig/MailConfig：只返回provider/host/model/能力/是否已配置秘密，不返回secret_ciphertext或明文。更换配置建新修订；模型URL只允许预设内网/官方目标清单，禁用任意URL探测。MailConfigWrite包括SMTP连接/TLS/发件地址/PUBLIC_BASE_URL/可选秘密；测试收件人由管理员显式指定。

TaskAccepted：{task_id,state,poll_url}；TaskView只含有权限关联实体、状态、进度、error_code、retryable，无模型输入全文。进度未量化的阶段显示阶段名，不编造62%等数值。

## 4. 错误码与处理

| HTTP | code示例 | 客户端行为 |
|---|---|---|
| 400/422 | INVALID_INPUT / FILE_TYPE_UNSUPPORTED / INVALID_RULE | 标出字段，不创建部分非法业务 |
| 401 | SESSION_EXPIRED / INVITATION_INVALID | 重新登录或核验，不显示其他考次 |
| 403/404 | PERMISSION_DENIED / RESOURCE_NOT_FOUND | 禁止访问，不按前端隐藏代替鉴权 |
| 409 | VERSION_CONFLICT / DUPLICATE_APPLICATION / MERGE_CONFLICT / IDEMPOTENCY_MISMATCH | 刷新或展示冲突供HR处理 |
| 409 | EMAIL_REQUIRED / DUPLICATE_UNRESOLVED / PAPER_NOT_PUBLISHED / AUTOMATION_DISABLED | 显示具体前置原因，不发送邮件 |
| 409 | EXAM_NOT_STARTED / EXAM_DEADLINE_REACHED / EXAM_ALREADY_FINALIZED | 保持服务端状态，不重开计时 |
| 410 | INVITATION_EXPIRED / INVITATION_REVOKED | 提示联系HR；不自动生成新考次 |
| 413 | FILE_TOO_LARGE | 限制大小和页数 |
| 429 | RATE_LIMITED | 按Retry-After重试，验证码限错 |
| 503/504 | MODEL_UNAVAILABLE / SEMANTIC_INDEX_UNAVAILABLE / DEPENDENCY_TIMEOUT | 显示不可用/转待办，不伪造成功 |

## 5. 特别一致性规定

同一岗位自动邀请只针对首次auto_allowed评估；手动覆盖不会自动发卷，HR需显式手动邀请。重评、新简历、改条件均不自动制造新考次。岗位暂停取消未发邮件时invite_status=revoked，notification=cancelled；sending仅是notification中间状态。已发出的邀请是否允许开考按岗位状态检查，已开考允许完成。

验证码邮件和考试邀请使用同一邮件适配器但不同purpose与限频，验证码发出不等于invite已读。所有邮件日志隐藏入口token/验证码。新轮次不得与旧活动考次并存；合并后按canonical人才与主application校验，历史引用原始ID不变。

招聘看板按authorized岗位过滤；人才总量按canonical根去重；平均分按finalized考次的当前score_report计算，重考默认取各application最新finalized轮次。候选人页不得调用reports/grading/profile/knowledge等后台接口。

培训框架只使用前端规划说明，无伪造训练执行接口。第一版无NL2SQL、视频面试、通用编排API。

邮件配置修订须先test验证再activate；首次发送冻结active的mail_config_id。排队时该配置停用则阻止发送并进入待办，HR明确resend时采用当时active修订，创建新的notification并保存对应mail_config_id，不改旧发送记录。验证码也记录实际邮件修订。正式SMTP必须TLS；仅本地隔离测试Mailpit可none。

## 一期请求类型与接口归属补齐

已实现请求/响应以实际OpenAPI为精确结构，以下固定剩余核心语义：

- TalentSearchQuery={query:string(1～2000),filters?:{skills:[],education?:string,major?:string,page_size?:1～100},page_size?:1～100}；只读语义POST仍需HR会话/CSRF。基本TalentListQuery另有q/status/page，不能复用此过滤类型冒充分页。
- EvaluationRequest={resume_version_id?:positive_id,reason:string(1～500)}；如提供简历必须当前且与画像同源；重评manual_only。OverrideRequest={reason,decision:"continue"}，不可注入状态/上下文。
- InvitationRequest={evaluation_run_id:positive_id,reason:nonempty,manual_override?:bool}；NewRoundRequest={paper_version_id,evaluation_run_id,reason}。服务端重读当前run/技术前提，不信任客户端自报eligible。自动要求pass/valid/达线/开关及auto_allowed；人工例外需显式reason，保留原未知/失败，不绕技术门。重复同轮返回同考次，活动考次不能另开新轮。
- StageTransition={to_stage,reason,expected_version}；InterviewNote={evaluation,interviewed_at}；ReviewCommand={score,reason,expected_revision}；禁止客户端传最终总分。可空、边界与错误码由实现时对应Pydantic/OpenAPI一并冻结并补契约断言，不凭简写补造字段。
- 读查询DTO字段与稳定分页精确规范见09的T28a/b/c；旧附录B的handler名不是强制命名。032/036属于search/router，037属于recruitment/router；匹配读取归evaluation，配置读取归原领域，runtime仅技术视图。
