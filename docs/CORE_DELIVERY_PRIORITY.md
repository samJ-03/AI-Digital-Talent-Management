## 不可省略的质量要求

- HR与管理员分工、部门私有数据隔离；考试/面试评价不能写入共享画像或共享向量。
- 发布岗位与试卷快照不可原位修改，写操作有必要的版本冲突控制、幂等与审计。
- 硬条件未知或失败不得直接冒充通过；优秀但有条件例外者保留原结果和人工理由。邮箱、有效岗位、发布试卷等技术前提不能被人工覆盖绕过。
- 自动邀请默认关闭；开启只产生持久扫描事件，T22/T23消费者完成前不能称为已自动发信。
- 同人同岗位的考次与邮件防重、服务端计时和统一提交、成绩人工复核、候选人不可见答案/私有评价。
- 企业SMTP未接入时以本地Mailpit验收，并明确外部候选人收信还未验收；不能将本地测试当生产交付。
