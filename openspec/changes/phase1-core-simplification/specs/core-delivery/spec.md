# core-delivery

## ADDED Requirements

### Requirement: Core scope only
Phase one SHALL include only the recruitment core and its necessary security, correctness and delivery checks.

#### Scenario: Optional capability exists
- **WHEN** T20 backend is already implemented
- **THEN** retain it as optional and do not require advanced semantic UI or knowledge workflows for core delivery

### Requirement: Executable current contracts
Documentation SHALL match current evaluation, task lease and public boundary semantics.

#### Scenario: New assessment starts
- **WHEN** a new evaluation is accepted
- **THEN** current pointer changes in that transaction and an older score cannot invite on its behalf
