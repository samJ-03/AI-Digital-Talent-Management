# Context
唯一任务基线docs/specs/09 T17，约束见04/05、MODEL_GATEWAY_CONTRACT和T15/T16契约。

# Decisions
模型只选择已确认简历事实，完整叶子引文不可截断；摘要为有来源事实拼接，不新增性格/稳定性预测。手工画像修订可重选/编排简历事实，新增事实先走简历修订。每条内容绑定resume_version和字段定位。考试与面试不进入模型输入/共享持久化，按当前部门及细分权限动态投影；成绩只来自当前正式ScoreReport，无维度数据雷达为null。

# Transactions
生成prepare在短事务外调用模型，finalize复验root/状态/当前简历及画像指针/配置/来源后原子提交，与worker租约同事务。不覆盖HR处理中新增的版本。恢复事件与后继任务同事务，失败旧处理器任务按配置修订幂等恢复，真实模型输出失败不无限重试。

# Risks
抽取式摘要表达较克制，但每个事实可以核实；自由改写可能引入新推断，因此新增事实先修订简历。管理员仍需发布匹配schema并显式启用profile工作流。
